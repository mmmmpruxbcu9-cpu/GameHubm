# GameHub — خانه بازی‌ها

نسخه آفلاین اندروید بر پایه فایل GameHub فعلی.

- شطرنج، دوز و ۲۰۴۸ حفظ شده‌اند.
- ورودی/بخش دوئل آنلاین حذف شده است.
- اجرای بازی‌ها از `assets/gamehub-1.html` انجام می‌شود.
- نام برنامه: GameHub | خانه بازی‌ها
- شناسه برنامه: com.gamehub.games

## ساخت APK
این پروژه را با Android Studio باز کنید و از مسیر:
Build > Build APK(s)
خروجی بگیرید.
